# External deploy/ audit

**Path inspected:** `/mnt/opt-inspect/home/git/operation-dbus-proto/deploy/`
**Compared against:** `/home/admin/git/odbus/deploy/`, `install/`, `CLAUDE.md`, `AGENTS.md`, `HANDOFF-2026-07-20-NETWORK-GRPC.md`
**Date:** 2026-07-20

## Executive summary

The external `deploy/` tree is **largely deprecated**. The canonical deployment
for the current codebase is generated by `install/3tched-artix-s6-install.sh` and
adjusted by `install/3tched-network-bootstrap.sh`. Anything that assumes
systemd, dinit, netplan, host WireGuard, AF_XDP, port 18789, `op-grpc-bridge-zeroclaw`,
`op-openvswitch-daemon`, `ghostbridge`, or host nginx/Caddy is retired.

Files that are **real / usable** in the current tree are mostly the small
configuration templates, helper scripts, and packaging assets that are already
mirrored (with updates) in the current repo's `deploy/`.

## Category definitions

- **Real / Done** — current, usable, or already reflected in the current repo.
- **Deprecated** — obsolete; kept for archaeology but should not be run on a
  current system.
- **Bad / Dangerous** — will actively break or reintroduce retired/forbidden
  paths (AF_XDP, host WG, removed daemon, etc.).
- **Not planning** — experiments or alternate-init paths that are not part of
  the current Artix-s6 design.
- **TODO** — conceptually valid but needs updating before it is accurate.

## Recommended actions

1. **Do not run** any script from the external `deploy/` tree on a current system
   without first checking this audit. The safest assumption is that external
   deploy files are deprecated unless they appear in the current repo's `deploy/`.
2. **Delete or archive** the most dangerous items (`apply-afxdp-boot.sh`,
   `cutover-afxdp.sh`, `install-op-openvswitch-daemon.sh`, `op-xdp-wg/`,
   `s6/op-openvswitch-daemon`, `s6/op-grpc-bridge-zeroclaw`, `s6/wg-*`,
   `s6/zeroclaw-*`, `s6/gbr-*`) from any active copy to prevent accidental use.
3. **Update `s6/`** to match the current service graph generated by
   `install/3tched-artix-s6-install.sh` and `install/3tched-network-bootstrap.sh`.
4. **Keep** the mirrored assets (`config/`, `dbus/`, `incus-hooks/`, `mcp/`,
   `monitoring/`, `netmaker/`, `nextdns/`, `qdrant-*.yaml`, `btrfs-layout.sh`,
   `build-sdbusplus-s6.sh`, `PKGBUILD-sdbusplus-s6`, `deploy-blob-gemma4.sh`,
   `novnc-ovs-cutover.sh`) but ensure they are the current-repo versions, not the
   external ones.
5. **Rewrite `AGENT-INTEGRATION.md`** and `base-components.md` if they are to be
   kept as living documentation, or move them to `docs/.consolidation-staging/`
   as historical artifacts.
