# UI Components

## Layout

- `AppShell` - Main layout wrapper with sidebar and header
- `Sidebar` - Navigation menu
- `Header` - Top bar with search and quota meter

## Data Display

- `DataTable` - Generic table with sorting
- `VirtualList` - Virtualized list for large datasets
- `LoadingSpinner` / `Skeleton` - Loading states
- `PayloadViewer` - JSON viewer with mask/unmask

## Forms

- `SearchInput` - Search with suggestions
- `ConfirmModal` - Confirmation dialog

## Security

- `RBACGate` - Role-based access control wrapper
- `QuotaMeter` - Visual quota usage indicator

## Visualization

- `MetricChart` - Line/area/bar charts (Recharts)

## Chat

- `ChatPanel` - Chat container
- `ChatMessage` - Message bubble
- `ChatInput` - Message input with send
