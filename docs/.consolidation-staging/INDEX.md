# Historical deployment concepts archive

This directory holds concept documents from the early prototype tree
(`/mnt/opt-inspect/home/git/operation-dbus-proto/`). They are preserved so
that ideas, plans, and alternate designs remain accessible even though the
current system has moved to a different architecture.

**Status:** historical / for reference only. The current canonical deployment is
`install/3tched-artix-s6-install.sh` + `install/3tched-network-bootstrap.sh`.

## Intentionally left behind

Operational scripts, deployment-specific configs, runtime logs, and large
conversation dumps were **not** copied:

- `install.sh`, `upgrade.sh`, `uninstall.sh`, `deploy.sh`, `base-install.sh`,
  `install-services.sh` — superseded by `install/3tched-artix-s6-install.sh`.
- `systemd/` directory — current system uses s6, not systemd.
- `dinit` references (Chimera) — not the current init.
- `netplan/`, `dnsmasq/`, `nginx/`, `caddy/` — host networking stack is now OVS
  system datapath + host Xray.
- `apply-afxdp-boot.sh`, `cutover-afxdp.sh`, `op-xdp-wg/` — AF_XDP on the host
  is forbidden in the current architecture.
- `install-op-openvswitch-daemon.sh`, `s6/op-openvswitch-daemon` — the daemon
  was removed from the tree; OVS is driven natively over OVSDB JSON-RPC.
- `ghostbridge/`, `setup-ghostbridge-public.sh`, `s6/gbr-*`, `s6/zeroclaw-*`,
  `s6/wg-*`, `s6/op-grpc-bridge-zeroclaw` — ghostbridge, zeroclaw, separate
  Zeroclaw bridge, and host WireGuard are retired.
- `netmaker/compose.yaml`, `incus-compose.yaml`, `install.sh` — deployment-specific
  Netmaker container orchestration with hardcoded IPs/license keys; left in the
  external tree.
- `s6/recompile-and-update.sh` — useful utility, but it invokes raw `s6`/`s6-rc`
  commands directly. The current bootstrap scripts already handle s6 recompilation,
  and routine service management must go through `sudo service6` per `AGENTS.md`.
- `fix-*.sh`, `setup-*.sh`, `check-*.sh`, `verify-*.sh` — band-aids and setup flows
  for the retired architecture.
- Root-level working text files (`projection.txt`, `schema-work.txt`,
  `assistant-work.txt`, `hypervisor.txt`, `incus-unix-socket.txt`,
  `zeroclaw-handoff.txt`, `netmaker.handoff`, `fable-handoff.txt`, etc.) —
  raw working notes from the prototype; concepts are captured in the preserved
  documents above.
- Conversation logs and archives (`FULL_CONVERSATION_HISTORY_*.md`,
  `RAW_CONVERSATION_HISTORY_*.jsonl`, `CODEX_RAW_DATA_*.tar.gz`,
  `recycled-bin/`, `gemini-conversation-*.json`) — chat history, not design docs.
- Clippy/JSON logs, `cookie.txt`, `crate-audit.zip`, proto zip files, and other
  build/runtime artifacts.
- `docs/reference/proto/op-openvswitch-daemon/` — protos for the removed daemon.
- `docs/operations/xdp-afxdp-conversation-2026-05-23.md` — retired AF_XDP path.
- `.kiro/` and `.zenflow/` — already mirrored in the current repo root.

## How to use this archive

- If you are looking for a concept that was discussed during the prototype
  phase, start here.
- If you want to revive one of these ideas, compare it against the current
  architecture in `CLAUDE.md` and `docs/architecture/` before writing code.
- Do not run scripts from the external prototype `deploy/` tree on a current
  system without reviewing them against the current architecture.
