The one paragraph

A mesh you can trust, not just connect

Traffic flows through a hardened pipeline — decoy ingress, identity sled, Xray header injection, a per-hop interceptor — where every request is classified, routed, gated against machine-readable policy (OSCAL), and recorded into a tamper-evident hash-linked chain. An AI layer reasons over that verified history but cannot execute anything itself. Same codebase ships as a privacy edition or a compliance edition — one config flag decides which world you're in.

How it works

One governance pattern, every layer

Make the wrong thing impossible first; gate what's left; record everything. The same idea at three scales — Rust says code can't be wrong, schema says state can't be invalid, A.N.N.A. says action can't be unauthorized — and the chain says it's all on the record.

What's on every block

Identity vector × Mutation vector

Two structured vectors ride every entry in the chain. Together they make "who changed what, when, on whose authority" a provable query — and they're exactly what A.N.N.A. gates on.

Identity vector — the WHO

session_id = Argon2(PSK, salt=WG_pubkey)

Derived from the Netmaker WireGuard key. Stable, deterministic, unforgeable. Privacy mode: the key alone (anonymous, consistent). Compliance mode: resolves to a verified user.

Mutation vector — the WHAT-CHANGED

The mut class of the subid taxonomy: what kind of change, on what resource, under what OSCAL authority. Reads (obs) and changes (mut) are distinct classes — so you can prove nothing was altered, not just that it was logged.

Cross-examination becomes exact: identity #abc performed mut config.write on netmaker.peer at T, authorized by OSCAL authorizing-official. That's the receipt.

The semantic memory

Voyage vectors → searchable meaning

Identity & mutation vectors are structured provenance. Voyage vectors are meaning. Every block, document, and transcript is embedded by voyage-code-3 into Qdrant — so the chain isn't just verifiable, it's searchable by similarity. This is the bottom pane when you cross-examine the agent, and the raw material the loop reasons over.

Embed

voyage-code-3 turns each chunk of the chain (actions, configs, docs, transcripts) into a high-dimensional vector. Code-aware, so it understands infra, not just prose.

Store & search

Vectors land in Qdrant, keyed notebook:source:chunk. Ask "show me peers like the one that misbehaved" — similarity, not keywords.

Rebuildable

Qdrant is a derived projection of the chain. Lose it in a disk casualty → re-embed from the canonical blocks. Trust lives in the chain; retrieval lives here.

Two vector families, two jobs: Voyage = "find things like this" (semantic). Identity / mutation = "who did exactly this, and was it allowed" (provenance). The AI uses both — meaning to reason, provenance to prove.

Why it's different

Four things nobody else can credibly claim

A brain with no hands

The AI is a delegator, recommender, fixer — and that's the ceiling. No internet, no execution rights, no execution control. It proposes into a schema-shaped mold; a separate, OSCAL-gated, chained layer disposes. A compromised model can't do damage — worst case is a rejected suggestion.

You can cross-examine it

Every action is a chained, searchable block. Confront the agent in real time — "why did you do this?" — and it answers with cryptographic receipts pulled live by semantic search. If the model confabulates, the evidence pane contradicts it. An AI you can put on the stand.

The chain is the truth

The hash-linked chain is canonical and tamper-evident. Qdrant + Cozo are AI-rebuilt projections of it — lose them, re-derive them. It's a snowball by structure, kept honest by anchoring, not consensus — the right call for a single-operator compliance ledger.

Schema-native, all the way down

Components were chosen because they're schema-based from the ground up (e.g. zeroclaw), and the code is safe by construction (Rust — memory-safe, race-free, single static binaries). Governance holds at every layer because nothing was bolted on.

For Netmaker specifically

A control server with no network interface

The netmaker, netmaker-mq (Mosquitto) and netmaker-ui containers run loopback-only. Exposed to the host as unix sockets via Incus proxy devices; wg-xray + Xray terminate TLS and route by SNI to those sockets. A port scan of the Netmaker server returns nothing.
