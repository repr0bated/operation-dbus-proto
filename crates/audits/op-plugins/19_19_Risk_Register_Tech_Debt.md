# Prioritized Production Security and Quality Risk Register

| Severity | Issue | Evidence | Recommendation |
| :--- | :--- | :--- | :--- |
| **Critical** | **Path Traversal to Arbitrary File Write & Root Code Execution** | `crates/op-plugins/src/state_plugins/pcidecl.rs:145` | Strictly validate the `item.address` field using a regular expression (e.g., verifying it matches a standard PCI BDF format `^[0-9a-fA-F]{4}:[0-9a-fA-F]{2}:[0-9a-fA-F]{2}\.[0-9a-fA-F]$`) before utilizing it in filesystem operations. Do not construct file paths via unsanitized format strings. |
| **Critical** | **Path Traversal to Host Configuration Overwrite** | `crates/op-plugins/src/state_plugins/lxc.rs:367` | Validate the `container.id` input to ensure it is strictly numeric or alphanumeric with no path separators (`/`, `\`) or parent directory traversal tokens (`..`). |
| **Critical** | **Arbitrary Host BTRFS Snapshot Creation and Data Leakage** | `crates/op-plugins/src/state_plugins/lxc.rs:265` | Enforce a strict whitelist of safe, alphanumeric golden image names. Sanitize `golden_image_name` to prevent directory traversal and verify that the resolved path resides strictly within the designated template directory. |
| **Critical** | **Insecure Static Temporary File & Symlink Race Condition** | `crates/op-plugins/src/state_plugins/dnsresolver.rs:126` | Use a secure temporary file creation library (such as the `tempfile` crate) to generate cryptographically random, unique temporary filenames, or open the temporary file with `O_EXCL` and `O_NOFOLLOW` to mitigate symlink hijacking. |
| **High** | **Schema-as-Code Violation: Ad-hoc Data Contracts and Lack of Versioned Schemas** | `crates/op-plugins/src/chat.rs:12`<br>`crates/op-plugins/src/state_plugins/incus.rs:16`<br>`crates/op-plugins/src/state_plugins/mcp.rs:17`<br>`crates/op-plugins/src/state_plugins/rtnetlink.rs:17`<br>`crates/op-plugins/src/state_plugins/web_ui.rs:56` | Standardize all core control plane data contracts, state snapshots, and configurations on versioned Protocol Buffers or strictly defined, centralized schemas. Validate dynamic input against these centralized schemas before application. |
| **High** | **Broken Shell Syntax and Always-Failing APT Execution** | `crates/op-plugins/src/state_plugins/netmaker.rs:268` | Refactor the command execution into two separate subprocess invocations (one for `update`, and one for `install`), or delegate package management to the `packagekit` plugin which handles operations over structured D-Bus interfaces. |
| **Medium** | **Unnecessary Subprocess Spawning of `cat` for Filesystem Reading** | `crates/op-plugins/src/state_plugins/dnsresolver.rs:92` | Eliminate the subprocess invocation entirely. Use Rust's native asynchronous file system API `tokio::fs::read_to_string` to safely and efficiently read the file content. |
